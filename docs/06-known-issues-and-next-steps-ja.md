## 現行設計上の制約

- 実際の3D形状・テクスチャを作る仕組みはない。角度間の補間もなく写真の切り替え。
- 撮影角度と高さの割り当ては手動。ガイドの位置が利用者の動きに追従して自動判定するわけではない。
- 動画からの前後コマ移動は時刻ベース。可変フレームレートの厳密な一コマ移動は保証しない。
- 読み込み動画は5分・400MBまで。対応コーデックは端末依存。
- 今回録画する動画は一時用途。完了後は写真だけを残す。元動画保存や後からの再切り出し管理は未実装。
- API 26では縮小前のフレーム取得が必要で、高解像度動画のメモリ負荷が確認対象。
- 途中でOSがプロセスを終了した場合、キャッシュ・復帰・一時URIの状態遷移の確認が必要。
- HTMLは閲覧用で、元の編集データとしての再取り込みには対応していない。
- サーバー同期、クラウド同期、PC編集アプリ、ストア公開の仕組みは実装していない。これらは今回の明示要望でもない。
