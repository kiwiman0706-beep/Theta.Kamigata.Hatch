## くるりヘア 1.1.0（versionCode 10100）

子どもの髪型を前・後ろ・左右・斜め・真上から撮り、指でドラッグして角度を切り替えて見返すAndroidアプリです。
昔のQuickTime VRの「Object Movie」のイメージで、AIによる3D生成ではなく**実際の写真を角度別に切り替えます**。
このリリースは、前の開発スレッドで2026-10-03に提供した署名済みAPKを**そのままのバイト列で**公開したものです（再ビルドなし）。

### 主な機能
- 9／17／25方向の撮影プラン、方向ごとの説明・頭の枠・撮影位置の図・前の写真の重ね表示
- 左右・上下ドラッグ、ピンチ拡大、自動回転のQTVR風ビューア、写真ごとの位置・倍率・回転補正
- 動画の撮影／読み込み → 一時停止・スライダー・前後コマで場面を選び、方向を指定して保存
- 写真を埋め込んだ単体で開けるインタラクティブHTMLの書き出し、ZIPバックアップ／復元
- 完全オフライン（INTERNET権限なし）。アカウント・APIキー不要

### 1.0.0からの変更
- カメラのプレビューが90°横向きになる不具合の修正コード（センサー回転の二重適用を解消）
- 動画から良いフレームを切り出す機能を追加

### インストール
- Android 8.0以降。`kururi-hair-1.1.0.apk` をダウンロードし、「提供元不明のアプリ」を許可してインストールします。
- 1.0.0を入れている端末は**アンインストールせず上書き更新**してください（同じ署名なので記録が残ります）。
- パッケージ `jp.yaegaki.kururihair`／署名証明書 SHA-256: `081a9477c8c8a1997d6d3a376566fdd2102a984f89550095fe9eda760fce0d20`（リリースCIで `apksigner` 検証済み）
