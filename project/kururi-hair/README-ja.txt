くるりヘア 1.1.0
更新日：2026年10月3日

■ 1.1.0の更新
動画の撮影・読み込みと、一時停止した場面を方向ごとの写真にする機能を追加しました。
スライダーと前後のコマ移動で選び、一本の動画から複数方向を保存できます。
カメラプレビューにセンサーの回転を重ねてしまい、縦向きの映像が90°横を向く問題を修正しました。
表示の回転を画面の回転だけにし、縦横比を保って中央に表示します。
撮影JPEGは引き続きセンサーと画面の向きに応じた回転を指定します。
同じパッケージ名・同じ署名鍵での上書き更新です。端末内の記録は引き継ぎます。

子どもの髪型を、いろいろな方向から撮った写真で保存するAndroidアプリです。
左右・上下にドラッグすると、角度ごとの写真が切り替わるQTVRオブジェクト形式の閲覧です。

■ インストール
kururi-hair-1.1.0.apk をAndroid端末で開いてインストールしてください。
必要なら、APKを開いたアプリの「この提供元のアプリを許可」を有効にします。
Android 8.0以上。Android System WebView / Chromeは更新済みのものをご利用ください。
アプリ名は「くるりヘア」、パッケージ名は jp.yaegaki.kururihair です。

■ 最初の撮影
1. 「髪型の記録をつくる」を押します。
2. 名前・髪型のタイトル・日付を入力します。
3. 9枚・17枚・25枚の撮影プランを選びます。おすすめは17枚です。
4. 「保存して撮影へ」→「未撮影の方向を順に撮る」を押します。
5. カメラの使用を許可します。
6. 指定された方向へ移動して、頭をガイド枠に合わせて撮ります。
7. 撮った写真を確認し、「保存して次へ」を押します。

お子さんは座って正面を向いたまま、撮る人が周囲を移動します。
右・左はお子さんの右・左です。
少し高い位置からの写真は、およそ35°見下ろすように撮ります。
最後は頭の真上から、つむじを中央に撮ります。
角度はガイドを見ながら手動で合わせます。位置や撮影方向の自動判定は行いません。

1枚ずつ保存するので、撮影を中断しても保存済みの写真は残ります。
「あとで撮る」で特定の方向を飛ばすこともできます。
「前の写真：ON」で、前に保存した1枚を薄く重ねて位置合わせできます。
撮影方向のマスをタップすれば、1枚だけ撮る・撮り直す・既存写真から選ぶこともできます。

■ 動画から良い瞬間を選ぶ
1. 記録の「撮影する・撮り足す」または「写真を確認・撮り直す」を開きます。
2. 「動画からまとめて選ぶ」を押します。
3. 「動画を撮影する」または「既存の動画を選ぶ」を選びます。
4. 撮影は端末のカメラアプリで行います。60秒以内の短い動画がおすすめです。
5. 正面 → お子さんの右側 → 後ろ → 左側と、同じ距離でゆっくり移動します。
   斜め上・真上も撮っておくと、あとからそれぞれの方向に割り当てられます。
6. 動画を再生し、良い場面で一時停止します。音声は再生しません。
7. スライダーで位置を選び、「前のコマ」「次のコマ」で細かく動かします。
8. 保存先の方向を上のメニューで選び、「…として保存」を押します。
   保存済みの方向を選んだ場合は「この方向の写真を置き換える」と表示します。
9. 一枚保存すると次の未保存方向へ進みます。同じ動画から別の場面を選んで続けられます。
10. 「完了」で戻ると、保存した写真を指で回して見返せます。

撮影方向のマス → 「動画の一場面から選ぶ」でも開始できます。
この場合はその方向が最初に選ばれ、ほかの方向にも続けて保存できます。
写真は1枚ずつ保存するので、途中で戻っても保存済みの写真は残ります。
保存した写真は通常の写真と同じように位置合わせ・ZIPバックアップ・画像埋め込みHTML出力できます。

読み込める動画は5分・400MBまでです。形式・コーデックは端末の対応に依存します。
時間に最も近いフレームを抽出します。前後のコマ移動の間隔は動画のフレーム数や撮影レートから求めます。
可変フレームレートでは、前後のコマ移動はおおよその間隔になります。
今回アプリから録画した動画は切り出しのための一時ファイルです。「完了」後は削除します。
アプリに残るのは選んだ写真です。必要な方向を選んでから完了してください。
既存の動画を読み込んだ場合、元の動画は変更・削除しません。
撮影方向の自動認識・自動シャッターは、この版には含みません。

■ 見返す
左右にドラッグ：周囲の写真を切り替え
上にドラッグ：斜め上 → 真上へ
下にドラッグ：頭と同じ高さへ
ピンチ / 拡大ボタン：写真を拡大
拡大中にドラッグ：写真を移動
▶ボタン：撮影した写真で自動回転
方向や高さのボタン：写真を直接選択
位置合わせボタン：位置・大きさ・90°単位の回転を調整

写真がない方向は撮影済みの方向へ切り替わります。
撮影枚数が多いほど細かい角度で回せます。

■ バックアップ・共有
「設定」→「すべての記録をバックアップ」で、写真・メモをZIPに保存できます。
機種変更時はZIPを新しい端末へ移し、「バックアップを読み込む」で復元できます。
同じIDの記録はバックアップの内容に戻ります。別の記録はそのまま残ります。
全ファイルを検証してから置き換えます。破損したZIPや不正なパスは読み込みません。
読み込みは展開後700MBまでです。

各記録の「書き出す」から、その記録だけをHTMLファイルにできます。
写真・メモをファイルに内包しており、ネット接続なしにPCのブラウザで回して見られます。
ZIPは再編集・復元用、HTMLは家族や美容室へ見せる閲覧用です。
HTMLをAndroid上で開けるかどうかは、ファイルを開くアプリの対応によります。

■ 保存
アカウント登録・サーバー・AIサービスは使いません。
写真は長辺1800px以下のJPEGへ正規化して端末内に保存します。
元の画像に含まれる位置情報などは、このJPEGには引き継ぎません。
髪型の記録は500件までです。
アプリをアンインストールすると端末内の写真と記録が消えます。
その前にZIPバックアップを保存してください。

■ ソースとビルド
ネイティブ：Java / Camera2 / MediaMetadataRetriever / VideoView / Storage Access Framework
画面：アプリに内包したHTML・CSS・JavaScript（WebView）
外部のAndroidライブラリやサーバーは不要です。

必要なもの：JDK 17、Android SDK platform 35、build-tools 35.0.0、Bash、zip
ビルド例：
  ANDROID_SDK_ROOT=/path/to/android-sdk bash build-apk.sh
単体テスト：
  node --test tests/core.test.cjs
カメラの向き計算の確認：
  bash tests/test-camera.sh
ブラウザUI確認：
  npm install --no-save playwright @sparticuz/chromium
  node tests/ui.test.cjs
テスト用ブラウザの種類・環境によっては別途ランタイム依存関係が必要です。

signing/kururi-personal.jks は、この個人用APKのアップデート署名鍵です。
既存の記録を保ったまま更新するため、同じパッケージ名と署名鍵を使ってください。
このソースZIPは署名鍵も含むため、個人で保管してください。
デフォルトの個人用ビルド用パスフレーズは build-apk.sh に記載されています。
後のバージョンではversionCode / versionNameを上げてビルドします。

Android SDKはソースZIPに含みません。
